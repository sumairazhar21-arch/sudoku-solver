# 🧩 Sudoku Game

A simple and interactive Sudoku game built using basic programming concepts. This project demonstrates logic building, problem-solving, and user interaction.

## 📌 Features

- ✔️ 9x9 Sudoku Grid
- ✔️ User input support
- ✔️ Validation of moves
- ✔️ Solution checker
- ✔️ Simple and clean interface

## 🚀 How It Works

1. The game displays a Sudoku grid.
2. User fills empty cells with numbers (1–9).
3. The program checks:
   - Row validity
   - Column validity
   - 3x3 grid validity
4. If all rules are satisfied → ✅ You Win!
